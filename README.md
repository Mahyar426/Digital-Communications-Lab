This repository contains resources, notes, and experiments related to the Digital Communications Laboratory course. The course covers key concepts and practical implementations of analog and digital modulation techniques, channel coding, and error correction methods.

Repository Contents

Channel Coding

Understanding various types of channel coding: Block codes, Convolutional codes

Error detection and correction techniques including Hamming codes and parity check

Implementation and evaluation of convolutional coding efficiency

Modulation Techniques

Introduction to analog and digital modulation

Analog Modulation: AM (Amplitude Modulation), FM (Frequency Modulation), PM (Phase Modulation)

Digital Modulation: ASK, PSK, FSK, and QAM

Practical experiments and simulations using MATLAB

Practical Implementations

MATLAB GUI applications to demonstrate modulation and coding schemes

Code examples for simulations of modulation/demodulation and encoding/decoding processes

Learning Objectives

Understand the theoretical fundamentals of modulation and channel coding

Learn to implement and simulate modulation techniques and channel coding using MATLAB

Analyze system performance, including Bit Error Rate (BER), efficiency, and robustness against noise and interference

Tools Used

MATLAB: For simulation and graphical demonstrations
